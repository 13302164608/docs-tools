CSV 转 JSON：把 Excel / 表格导出的数据变成接口能用的 JSON 数组，字段名取第一行；勾选「数字/布尔/null 自动转类型」后，"1200" 会变成 1200，空单元格变成 null。JSON 转 CSV：把接口返回的 JSON 数组摊平成表格，字段取所有对象的并集，缺的格子留空，嵌套对象/数组会转成 JSON 字符串放进单元格。

常见问题

为什么下载的 CSV 用 Excel 打开不乱码？

下载时会自动写入 UTF-8 BOM，Windows 版 Excel 靠这个标记识别中文。如果公司电脑是老版本 Excel，可以勾上「用 CRLF 换行」。

JSON 是嵌套结构（对象里套对象）能转吗？

能转，但只能摊到第一层：嵌套值会变成一段 JSON 字符串放在单元格里。真正要展平多层（比如订单里的商品明细拆成多行），这属于数据清洗，可以直接找我代做。

文件有大小限制吗？

没有硬限制，取决于浏览器内存。几万行的 CSV 一般没问题，几十万行建议先用脚本处理。

数据会被上传吗？

不会。解析和转换全部在浏览器里完成，页面没有上传接口。
